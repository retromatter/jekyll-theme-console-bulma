jekyll-theme-console-bulma is a terminal-inspired Jekyll theme powered by Bulma CSS.

Built for hackers, developers, and anyone who prefers their blog to look like a terminal window.

## Features

- Multiple color palettes: Light, Dark, Hacker, Nord
- Monospace fonts throughout
- Dashed borders and blocky hover effects
- Fully responsive via Bulma CSS
- Zero JavaScript dependencies beyond the theme switcher
